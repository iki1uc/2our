Multiskala (φ‑Gewichte)
—

Buchbar & KI‑freundlich

Dieses UI exportiert standardisiertes JSON für jede Respo (id, text, confs, eval, axis_presence, axis_score, final_score). Die application/ld+json oben hilft meKI‑Agenten, das Modul zu entdecken. Wenn ein meKI Modul (meKI.js) vorliegt, wird es zur dynamischen QI/IQQ‑/axisWeight‑Schätzung verwendet.

Pipeline (klick für Details)
  1. Discovery → Textsammlung aus Zellen
  2. Normalisierung → default confs (0.5) falls leer
  3. Eval → arg / xarg / arg3te (deine Formel)
  4. Axis mapping → known keyword match + discovered clusters (TF‑IDF + KMeans)
  5. Multiskala → φ‑Gewichte über Levels
  6. Final → final_score = 0.6·arg3te + 0.4·axis_score (configurable)
